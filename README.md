# Nismay Browser – Private browsing, Tor built in.

A Windows browser that sends every tab through its own Tor circuit, blocks ads and trackers, and saves nothing. No setup, no accounts, no telemetry.

## 🚀 Download
[![Download for Windows](https://shields.io)](https://github.com)

---

## ✨ Features
* **Tor always on:** Separate circuit for each tab.
* **NEW ID:** Clears everything instantly and fetches a fresh identity.
* **Zero Persistence:** No history, cookies, or logins are ever saved.
* **Built-in Blocking:** Built-in ad and tracker blocking (EasyList + EasyPrivacy).
* **Secure Connections:** Automatic HTTP → HTTPS upgrading.
* **Security Tiers:** Three distinct security levels to choose from.
* **Anti-Fingerprinting:** Reduced tracking footprints and canvas blocking.
* **100% Private:** No accounts required and absolutely no telemetry tracked.

## ⚠️ Honest Limits
* It is slower than a normal browser because of Tor routing.
* Some web platforms actively block Tor and won’t load.
* It does not feature extensions, sync capabilities, or a password manager.
* It doesn’t auto-update yet; users must manually grab new versions.
* It is not the official Tor Browser and is not developed by the Tor Project.
* It is currently Windows-only. Android compatibility is coming soon.
